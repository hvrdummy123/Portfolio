### README summary

**Problem:** Want a personal aggregator over a fixed company list that polls real ATS/careers sources continuously and searches like a small job portal—without becoming multi-tenant SaaS or a scraping farm (docs/SYSTEM_DESIGN.md).

**What it does:** Single-user job aggregation: detect/poll Greenhouse, Lever, Ashby, Workday, SmartRecruiters, Oracle, Amazon connectors, plus generic careers-page reader (JSON-LD → sitemap → discovered JSON → HTML → Playwright). Stores normalized jobs in Postgres; React UI for search/filter/saved searches/source health; Apply opens original posting (no auto-apply). Seed lists ~500+ employers + Indeed/Wellfound/Naukri portal feeds.

**Stack:**
- Python 3.12
- FastAPI
- asyncpg
- httpx
- Playwright (Chromium)
- Postgres 16
- React + Vite + TanStack Query/Virtual
- Docker Compose (app + postgres)
- uv

**Features:**
- Pluggable ATS connectors + generic multi-stage page reader
- Parallel refresh with SSE progress (/api/events)
- Source health with fallback_stage and needs_playwright
- Saved searches with backfill over open jobs
- First successful poll per company is silent baseline (no new-job flood)
- Heal scripts for empty/zero-ATS companies
- SQL migrations 001–007
- Binds to 127.0.0.1:8000; no in-app auth (security note)
